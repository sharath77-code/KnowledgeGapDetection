Project Title: Explainable and Prerequisite-Aware Knowledge Gap Detection Using Machine Learning and Deep Knowledge Tracing for Personalized Learning
Abstract

Traditional online assessment platforms evaluate student performance based on static numerical grades without capturing latent cognitive knowledge gaps, problem-solving hesitation, or prerequisite dependency failures. This project proposes EduGap AI, an end-to-end explainable framework that combines Gradient Boosted Decision Trees and Deep Knowledge Tracing (DKT) to detect cognitive gaps and deliver personalized, session-aware remediation.

Utilizing 525,534 student interaction logs from the ASSISTments benchmark dataset across 20 mathematics skills, our system extracts 7 zero-label-leakage interaction attributes. Our top ML classifier (XGBoost) achieves 92.40% Accuracy and 0.9865 Macro ROC-AUC, while our PyTorch GRU DKT model achieves 92.25% Accuracy. The platform provides a dedicated /review portal with side-by-side answer comparison cards and print-ready A4 PDF study guides.

Introduction & Motivation

Problem Statement: Conventional E-learning tools treat quiz scores as binary pass/fail marks, ignoring response latency, repeated submission attempts, and hint dependencies. Students receive generic practice problems rather than targeted remediation.

Project Objectives:

  • Develop a zero-label-leakage behavioral feature extraction matrix.
  • Deploy a dual AI architecture combining tabular ML (XGBoost) and sequential Deep Knowledge Tracing (PyTorch LSTM, GRU, Transformer-DKT).
  • Construct a Graph Neural Network (GCN) to map prerequisite concept dependencies across 20 math skills.
  • Build a 4D Latent Space Knowledge Autoencoder to compress interaction friction into intuitive cognitive metrics.
  • Provide a dedicated answer review portal and session-aware PDF study guides.
Methods and Materials

1. Dataset & Preprocessing: Ingested 525,534 student interaction logs from ASSISTments. Applied median imputation for missing response times and mode encoding for tutor interaction types. Log-transformed response latency: log_ms_response = ln(1 + ms_first_response).

2. Behavioral Feature Engineering Matrix:

  • correct: Binary item score (1.0 or 0.0).
  • attempt_count: Repeated submission count.
  • hint_count & hint_ratio: Normalized hint reliance $\frac{\text{hint\_count}}{\text{hint\_total} + 1}$.
  • attempt_hint_sum: Combined problem friction index ($\text{attempt\_count} + \text{hint\_count}$).
  • user_skill_hints & user_skill_attempts: Longitudinal persistence memory.

3. Target Quantization: Stratified Knowledge Gap Index into 3 balanced target classes: High Gap (>50%), Moderate Gap (25–50%), and Low Gap (≤25%).

Discussion & Diagnostic Explainability

1. Explainability & Diagnostics: Multi-Class One-vs-Rest (OvR) ROC-AUC Curves (0.9865 Macro AUC) and Seaborn Confusion Matrices confirmed zero class bias across High, Moderate, and Low gap levels.

2. Prerequisite GCN & 4D Autoencoder: A 20-node Graph Convolutional Network mapped concept dependency pathways, while a symmetric Autoencoder ($7D \rightarrow 16D \rightarrow 4D \rightarrow 16D \rightarrow 7D$) compressed friction into 4 latent metrics (Mastery, Hesitation, Help Reliance, Velocity) with 0.0194 MSE Loss.

Conclusions

EduGap AI successfully bridges the gap between raw student assessment logs and explainable, actionable academic remediation:

  • Achieved 92.40% Accuracy using XGBoost and 92.25% Accuracy using PyTorch GRU DKT.
  • Engineered a zero-label-leakage 7-attribute behavioral interaction matrix.
  • Integrated prerequisite concept graph convolutions and 4D latent knowledge autoencoding.
  • Delivered session-aware remediation filtering and single-click print-ready A4 PDF academic study guides.
