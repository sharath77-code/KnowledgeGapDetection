Project Title: Explainable and Prerequisite-Aware Knowledge Gap Detection Using Machine Learning and Deep Knowledge Tracing for Personalized Learning
1. ABSTRACT

Traditional online assessment platforms evaluate student performance through static numerical grades, failing to capture latent cognitive knowledge gaps, problem-solving hesitation, hint dependency patterns, or prerequisite skill failures.

This project proposes EduGap AI, an end-to-end explainable framework combining Gradient Boosted Decision Trees and Deep Knowledge Tracing (DKT) to detect cognitive gaps and deliver personalized, session-aware remediation.

Utilizing 525,534 student interaction logs from ASSISTments across 20 math skills, our feature engine extracts 7 zero-label-leakage attributes (log_ms_response, hint_ratio, attempt_hint_sum, etc.).

Our top model (XGBoost Classifier) achieves 91.56% Accuracy & 0.9880 ROC-AUC, while PyTorch LSTM DKT achieves 85.77% Accuracy.

2. INTRODUCTION & OBJECTIVES
Problem Statement:

Conventional e-learning tools evaluate students purely on quiz accuracy, ignoring behavioral interaction cues like latency, repeated attempts, and hint reliance. Struggling students receive generic problems rather than targeted gap remediation.

Key Project Objectives:
  • 1. Feature Engine: 7 zero-label-leakage interaction attributes capturing latency and hint reliance.
  • 2. Machine Learning Benchmark: Decision Tree (81.56%), Random Forest (82.77%), XGBoost (91.56% Acc, 0.9880 AUC).
  • 3. Deep Learning Benchmark: 1D-CNN (84.97%), Simple RNN (85.47%), LSTM / DKT (85.77% Acc).
  • 4. Multi-Class Explainability: Validated via One-vs-Rest ROC-AUC curves (0.9880 AUC) & Seaborn confusion matrices.
  • 5. Dedicated /review Portal: Interactive side-by-side comparison cards (Your Answer vs Correct Answer).
  • 6. Session Remediation: Attended-topic recommendations (10 topics) with single-click print-ready A4 PDF study guides.
3. METHODS AND MATERIALS
1. Preprocessing Pipeline:

Ingested 525,534 interaction logs from ASSISTments across 20 math skills. Applied median imputation for latency, mode encoding for tutor modes, and log transformation: log_ms_response = ln(1 + ms_first_response).

2. Behavioral Feature Matrix (7 Core Attributes):
  • correct: Binary item accuracy score (1.0 = Correct, 0.0 = Incorrect).
  • attempt_count: Count of repeated problem submission attempts per item.
  • hint_count & hint_ratio: Normalized hint reliance = hint_count / (hint_total + 1).
  • attempt_hint_sum: Total problem friction index = attempt_count + hint_count.
  • log_ms_response & log_overlap_time: Log-scaled first response latency & total duration.
  • user_skill_hints & user_skill_attempts: Longitudinal student persistence memory.
3. Target Quantization:

Stratified Knowledge Gap Index into 3 balanced target classes: High Gap (>50%), Moderate Gap (25-50%), and Low Gap (≤25%).
